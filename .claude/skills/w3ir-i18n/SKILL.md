# Додавання рядків у W3IR Browser

Мова-джерело: українська. Рядок українською в коді є ключем, каталоги `locales/<код>.json` (en, pl, de, es, fr) мають вигляд `{"український рядок": "переклад"}`. Динамічні частини в ключі: `{0}`, `{1}`.

1. Пиши український текст цілим реченням. Не склеюй `'а' + x + 'б'`, використовуй шаблонний літерал (`node build/i18n-extract.js --concat` покаже склеєні місця). У головному процесі загортай у `tr('текст', арг…)`.
2. `node build/i18n-extract.js` оновлює `locales/_keys.json`; `node build/i18n-extract.js --check` показує, чого бракує в кожній мові.
3. Для кожної мови зроби файл-патч `{"український ключ": "переклад"}` і застосуй `node build/i18n-merge.js <код> patch.json` (перевіряє `{n}`, розмітку й сортує). Патч створюй файлом, не heredoc.
4. Не перекладаються: описи інструментів для моделі (`src/agent.js`, MCP), журнали, назви мереж і брендів, імена профілів. Внутрішні журнали пиши англійською.
5. Російської мови немає навмисно. Не додавай її.
6. Перед завершенням: `npm run test:unit`, а область i18n: `W3IR_ONLY=<функція i18n з test/security.js>` або `npm test`.

Деталі: `docs/I18N.md`.
