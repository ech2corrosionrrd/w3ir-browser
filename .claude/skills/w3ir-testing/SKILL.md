# Які тести запускати (W3IR Browser)

| Зміна | Команда |
|---|---|
| Чиста логіка (`util`, `urlrules`, `safe-fetch`, `qr`, `crypto-util`, `update-verify`, `injection-guard`, base58, SIWE тощо) | `npm run test:unit` (секунди) |
| Будь-який синтаксис | `node --check <файл>`, потім `npm run lint` |
| Одна область (вкладки, гаманець, ШІ…) | `W3IR_ONLY=<функція>` (імена в `test/security.js`) разом із `W3IR_USER_DATA=<тимчасова тека> W3IR_SMOKE=security npx electron .` |
| Перед завершенням задачі | `npm run lint` і `npm test` (≈3–5 хв, у вікні Electron) |
| Рядки інтерфейсу | `node build/i18n-extract.js --check` |
| RPC гаманця | `npm run check:rpc` (потрібен інтернет, не в CI-задачі) |

Правила:
- `W3IR_USER_DATA` задавати завжди, інакше тест торкнеться реальних даних або впреться в блокування одного екземпляра.
- Нова чиста функція: тест у `test/unit/`. Нова поведінка вікна й IPC: область у `test/areas/`.
- Тестове вікно видиме, не працюй у ньому вручну.
- Програмний клік не відтворює справжній: для кнопок перевіряй «повільний» клік (пауза 150 мс між подіями).
- Інструментальні сценарії (`test/installed-cdp.js`, mainnet/devnet скрипти) агент не запускає: їх запускає людина.
- Не вимикай і не послаблюй тест, щоб він пройшов.

Деталі: `docs/TESTING.md`.
