# Журнал змін

Версії 1.0.0–1.14.0 розроблені й випущені 2026-10-16. Формат: нові можливості, зміни, виправлення.

## 1.14.0
- **Новий дизайн за концепцією W3IR (весь інтерфейс):** темна тема в глибокому індиго замість нейтрально-сірої, лавандова світла; панель вкладок і адресний рядок із «сіткою даних», активна вкладка з градієнтною лінією бірюза → фіолет, неонове світіння поля адреси при фокусі, індиго-меню й палітра; сторінки браузера з м'якими неоновими відблисками, градієнтними заголовками, «скляними» блоками й акцентними смужками розділів; у налаштуваннях — бічна навігація розділами. Інкогніто лишається окремим (чорно-фіолетовий з маджентою).
- Фавікон на вкладках внутрішніх сторінок, значок застосунку й нова вкладка з концепції (з 1.11.0) тепер у єдиному стилі з рештою інтерфейсу.

## 1.13.0
- **Спільні вкладки для ШІ**: ви самі даєте Claude Code доступ до своєї вкладки (правий клік → «ШІ: дозволити читати / керувати», Ctrl+K). Два рівні — **читання** й **керування** (кліки, ввід, клавіші, прокрутка, вибір зі списку). Доступ прив'язаний до сайту, діє 30 хв, скасовується при закритті вкладки, вашому переході на інший сайт, закритті вікна чи вимкненні ШІ; перехід, ініційований ШІ, на новий сайт питає вас. Значок «ШІ» / «ШІ ✎» на вкладці. Паролі й картки ШІ не вводить і тут; вкладки не закриває; приватні й внутрішні сторінки ділити не можна.
- Нові інструменти: `browser_find`, `browser_wait_for`, `browser_select`, `browser_hover`. `browser_tabs` показує власні й спільні вкладки і не відкриває вікно ШІ без потреби.
- Під час підключення сервер передає моделі правила роботи (`instructions`); клієнт (назва/версія) видно в налаштуваннях і на Панелі; кнопки «Припинити спільні вкладки».
- Документація `docs/AI-MCP.md` (підключення, зони роботи, приклади, усунення проблем).

## 1.12.0
- **Панель** (`w3ir://dashboard`, меню, Ctrl+K, нова вкладка): Bento-картки — мережі гаманця з пінгом RPC (лише за кнопкою, `eth_chainId`, зелений = правильний chainId), адреса гаманця з копіюванням в один клік (буфер очищується через 20 с), керування браузером ШІ з перемикачем, стан захисту, журнал дій ШІ й гаманця.
- План розвитку переорієнтовано на Claude Code через MCP (`docs/PLAN.md`).

## 1.11.0
- **Фірмовий стиль W3IR** за концепцією (око з цифрою 3 у скляній сфері): новий значок застосунку, фавікон внутрішніх сторінок, зображення інсталятора (бічна панель і заголовок NSIS), нова вкладка з неоновими хвилями на глибокому індиго, «скляні» картки, знак і вордмарк «W3IR BROWSER».
- Акцент інтерфейсу й сторінок — фіолетово-індиговий; кнопки `primary` із градієнтом блакитний → пурпурний.
- `npm run icon` тепер генерує всі фірмові ресурси з концепт-зображень (`build/make-brand.py`); опис — `docs/BRANDING.md`.

## 1.10.1
- **Виправлено гаманець:** три вбудовані RPC не працювали (Ethereum — `llamarpc` віддавав 525, Polygon — `polygon-rpc.com` «tenant disabled», Sepolia — порожня відповідь). Замінено на `publicnode` (без ключів); усі 8 мереж перевірено онлайн. Додано `npm run check:rpc` і тест вбудованих адрес.
- У вікні під керуванням ШІ значок тепер «Керує ШІ» (раніше — «Інкогніто»).

## 1.10.0
- **Керування браузером ШІ (MCP)**: локальний сервер на 127.0.0.1 з токеном (DPAPI), окреме тимчасове вікно агента без ваших входів, підтвердження кожного нового сайту, заборона вводу в поля паролів і карток, завантажень і дозволів, захист від SSRF, журнал дій, зупинка в налаштуваннях і в палітрі. Інструменти: відкрити/перейти/читати/знімок елементів/клік/ввід/клавіші/прокрутка/скріншот. Довільного JavaScript немає.
- Налаштування → «Керування браузером ШІ»: перемикач, токен, готові команди підключення (Claude Code та JSON), порт, дозволені сайти, журнал.
