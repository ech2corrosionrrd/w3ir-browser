# Повідомлення про вразливості

**Не створюйте публічне обговорення (Issue) для вразливостей.** Використайте приватне повідомлення GitHub:
вкладка **Security → Report a vulnerability** у цьому репозиторії.

Що вказати: версія браузера (`w3ir://settings`), кроки відтворення, наслідки (що може зробити зловмисник). Відповідь — протягом кількох днів; після виправлення й випуску оновлення автора знахідки буде згадано в `CHANGELOG.md` (якщо не заперечуєте).

У межах уваги: обхід ізоляції внутрішніх сторінок і IPC, витік паролів чи ключів гаманця, підміна оновлень, обхід підтвердження дій ШІ чи гаманця, вихід із пісочниці. Модель загроз і криптографія — у [docs/SECURITY.md](docs/SECURITY.md).

Безпека проєкту не залежить від таємності коду: секрети (ключ підпису оновлень, паролі, ключі користувачів) ніколи не зберігаються в репозиторії. Публічний ключ перевірки оновлень — `src/update-key.js`, відбиток `fb850ffc878fa972`; будь-яка збірка, підписана іншим ключем, не буде прийнята встановленими копіями.
