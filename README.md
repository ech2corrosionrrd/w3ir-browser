# W3IR Browser

Браузер для Windows на основі Chromium: блокування реклами й трекерів, менеджер паролів із шифруванням, гаманець Web3, профілі, синхронізація закладок, режим читання, палітра команд (Ctrl+K), інтеграція з GitHub, світла й темна тема.

## Завантаження
Останню версію (встановлювач і портативну збірку) можна завантажити зі сторінки [Releases](../../releases/latest).

- **Встановлювач** (`W3IR-Browser-Setup-*.exe`) — рекомендовано: підтримує автооновлення.
- **Портативна версія** (`W3IR-Browser-*-portable.exe`) — без встановлення, автоматично не оновлюється.

Потрібна Windows 10/11 (x64).

> Програму не підписано сертифікатом видавця Microsoft, тому Windows SmartScreen може показати попередження («Windows захистила ваш ПК»). Натисніть «Докладніше» → «Все одно виконати», якщо ви завантажили файл із цієї сторінки.

## Автооновлення та безпека
Встановлена версія сама перевіряє оновлення на цій сторінці. Кожен реліз підписується ключем випускача (Ed25519); браузер встановлює лише оновлення з дійсним підписом, а підроблені, змінені чи старіші версії відхиляє.

Відбиток публічного ключа випускача: `fb850ffc878fa972` (його видно також у «Налаштування → Оновлення браузера»). У кожному релізі файл `latest.yml` містить підпис (`w3irSignature`) і той самий відбиток (`w3irKeyId`).

Цей репозиторій містить лише збірки релізів; вихідний код тут не публікується.

## Довідка
Після встановлення натисніть **F1** — довідка описує всі функції та гарячі клавіші.
