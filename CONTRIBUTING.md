# Як долучитися

1. Створіть гілку від `main`, зробіть зміну, запустіть `npm run lint` і `npm test` (потрібен робочий стіл Windows, ≈ 3–5 хв). На GitHub автоматично йдуть швидкі перевірки (lint, unit, audit, пошук секретів); повний e2e — локально.
2. Нова функція — з тестами в `test/areas/`, записом у `CHANGELOG.md` і (якщо видима користувачу) в довідці `pages/help-data.js`.
3. Принципи: безпека й приватність понад усе (мережа й секрети — вимкнено за замовчуванням), без нових збирачів і фреймворків (HTML/CSS/JS, суворий CSP), мова інтерфейсу й коментарів — українська. Див. [docs/PLAN.md](docs/PLAN.md) і [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
4. **Ніколи не додавайте в коміт ключі, токени, `vault.*`, `.pem`.** Вразливості — лише приватно, див. [SECURITY.md](SECURITY.md).

Випуски підписує лише власник проєкту (приватний ключ не в репозиторії); зовнішні збірки встановлені копії не оновлюють.
