# Керування браузером через Claude Code (MCP)

W3IR Browser містить вбудований локальний сервер MCP. Claude Code (або інший клієнт MCP) підключається до нього зі **вашою підпискою Claude**: API-ключ не потрібен, браузер ключів Anthropic не бачить. Вимкнено за замовчуванням.

## Підключення (2 хвилини)

1. У браузері: **Налаштування → Керування браузером ШІ (MCP)** → увімкніть перемикач.
2. Натисніть «Показати» біля токена, скопіюйте команду з розділу «Claude Code» і виконайте її в терміналі:
   `claude mcp add --transport http w3ir-browser http://127.0.0.1:47821/mcp --header "Authorization: Bearer …"`
3. Запустіть (або перезапустіть) Claude Code. У налаштуваннях з'явиться рядок «✔ claude-code … підключився»; цей самий стан видно на сторінці **Панель**.
4. Спробуйте: «Відкрий example.com і скажи, який там заголовок».

Інші клієнти: JSON-конфіг у тому ж розділі. Порт можна змінити там само.

## Дві зони роботи

| | Вікно ШІ (власні вкладки) | Спільні вкладки (ваші) |
|---|---|---|
| Де | окреме тимчасове вікно, як інкогніто: **без ваших входів**, паролів, гаманця й історії | ваша звичайна вкладка в ваших вікнах, **з вашими входами** |
| Як починається | ШІ відкриває сторінки сам | **ви** вирішуєте: правий клік по вкладці → «ШІ: дозволити читати / керувати…» або Ctrl+K |
| Підтвердження | кожен новий сайт | один раз при наданні доступу; перехід ШІ на інший сайт знову питає |
| Що можна | усе: відкривати, читати, клікати, вводити текст, скріншоти | **читання** — текст, елементи, скріншот; **керування** — ще кліки, ввід, клавіші, прокрутка, вибір зі списку |
| Тривалість | до закриття вікна | 30 хв або до «припинити», закриття вкладки, вашого переходу на інший сайт |

На вкладці, до якої є доступ, видно значок **«ШІ»** (бірюзовий — читання, жовтий **«ШІ ✎»** — керування).

## Приклади запитів

- «Прочитай мою відкриту вкладку і зроби короткий конспект» → дайте доступ «читати».
- «У цій вкладці заповни форму: ім'я Олена, місто Київ» → «керувати» (паролі й картки ШІ не вводить).
- «Знайди на example.com, скільки коштує тариф Pro» → ШІ працює у власному вікні.
- «Порівняй ціни на трьох сайтах» → ШІ відкриває сайти й просить підтвердження кожного.

## Що ШІ не може (за будовою)

- Вводити паролі, дані платіжних карток, одноразові коди; значення полів паролів не потрапляють йому в знімок.
- Виконувати довільний JavaScript, читати cookie й сховища, завантажувати файли, відкривати `w3ir://`, `file:`, локальні й приватні адреси.
- Закривати ваші вкладки; діяти у вкладці в режимі «читання»; працювати в приватних вікнах; бачити менеджер паролів і гаманець.
- Діяти довше за 30 хв без вашого поновлення доступу.

Усе, що повертають сторінки, позначається як «недовірені дані»: Claude отримує вказівку не виконувати наказів із них. Під час підключення сервер передає моделі правила роботи (`instructions`): перед діями з наслідками (покупка, відправлення, видалення) ШІ має спершу повідомити вам, що збирається зробити.

## Зупинка

Кнопка «Припинити» у налаштуваннях і на Панелі · меню вкладки → «ШІ: припинити…» · команда «Зупинити керування браузером ШІ» (Ctrl+K) · закриття вікна ШІ · вимкнення перемикача.

## Якщо щось не працює

| Симптом | Причина й рішення |
|---|---|
| «Порт зайнятий» | Інша програма займає порт: змініть порт у налаштуваннях і виконайте команду підключення знову |
| Claude Code не бачить інструментів | Перезапустіть Claude Code після `claude mcp add`; перевірте `claude mcp list` |
| 401 / «unauthorized» | Токен змінився («Новий токен»): виконайте команду підключення знову |
| Клік не спрацьовує | Спершу `browser_snapshot` (сторінка могла змінитися); вікно ШІ не повинно бути згорнутим |
| «Вкладку надано лише для читання» | Правий клік по вкладці → «ШІ: дозволити керувати цією вкладкою…» |
| Нічого не відбувається у спільній вкладці | Доступ міг завершитися (30 хв, ваш перехід на інший сайт); поділіться знову |

Журнал дій (без введеного тексту й вмісту): налаштування, Панель і файл `agent.log` у теці даних. Технічні подробиці безпеки — [SECURITY.md](SECURITY.md).
