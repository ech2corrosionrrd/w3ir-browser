# Багатомовність

Мови інтерфейсу: **українська** (мова-джерело), English, Polski, Deutsch, Español, Français. Російської мови немає навмисно. Вибір — «Налаштування → Мова» (або «Як у системі»: за мовою Windows; `ru`/`be` → українська, невідома → English). Мова спільна для всіх профілів (як тема); зміна діє одразу, без перезапуску: перезавантажуються інтерфейс і внутрішні сторінки. Сайти не змінюються.

## Як це влаштовано

- **Рядки в коді українською — це ключі.** Каталоги `locales/<код>.json` мають вигляд `{"український рядок": "переклад"}`. Динамічні частини в ключі позначено `{0}`, `{1}`… (у коді — шаблонний літерал `` `Видалити профіль «${name}»?` ``, ключ — `Видалити профіль «{0}»?`). Немає перекладу — показується українська.
- **Головний процес** (`src/i18n.js`): `tr('текст', арг…)` для рідних меню, діалогів і сповіщень. Спільний екземпляр `i18n`, мову задає `settings:set` або `main.js` під час старту (`W3IR_LANG=uk|en|…` перекриває мову — для тестів; в автотестах `W3IR_SMOKE=security` завжди українська).
- **Сторінки й інтерфейс** (`pages/i18n-dom.js`): протокол `w3ir://…/i18n.js` віддає каталог і механізм перекладу. Він перекладає текстові вузли, `placeholder`/`title`/`aria-label`/`alt`, `document.title` і динамічно додані вузли (шаблони `{0}` зіставляються регулярними виразами; вставлені українські фрагменти теж перекладаються; багаторядкові підказки — по рядках). Елемент із `data-notr` не перекладається. Для української скрипт лише визначає `t()` і `LOCALE`.
- **Довідка** (`pages/help-data.js`) перекладається на рівні даних (`trAll` у `help.js`), бо розмітка `**…**`, `` `…` ``, `[текст](w3ir://…)` розбиває текст на кілька вузлів DOM.
- Дати й числа форматуються через `LOCALE` (`de-DE`, `fr-FR` …), одиниці (`Б`, `КБ`…) — через `t()`.

## Нові рядки

1. Пишіть український текст у коді цілим реченням (не склеюйте `'а' + x + 'б'` — використовуйте шаблонний літерал; `node build/i18n-extract.js --concat` показує склеєні місця). Для рідних меню/діалогів загорніть у `tr(...)`.
2. `node build/i18n-extract.js` — оновлює `locales/_keys.json` (перелік ключів); `--check` — показує, чого бракує в кожній мові, і перевіряє збіг підстановок `{n}` та розмітки.
3. Додайте переклади: `node build/i18n-merge.js en patch.json`, де `patch.json` = `{"український ключ": "переклад"}` (скрипт перевіряє підстановки й сортує файл).
4. Автотест (`test/areas/i18n.js`) падає, якщо в якійсь мові бракує рядка або розмітка розійшлась.

## Нова мова

`locales/<код>.json` з усіма ключами (`node build/i18n-extract.js --check` покаже повноту) + рядок у `LANGS` (`src/i18n.js`: назва мовою самої мови та BCP-47 для дат). Повноту, збіг розмітки й автовибір перевіряють тести.

## Не перекладається

Описи інструментів для моделі (MCP, `src/agent.js`), журнали (`updater.log`), назви мереж і брендів, імена профілів і файли користувача. З `agent.js` беруться лише видимі користувачу рядки (`title`, `label`, `message`, `detail`, `toast`).
