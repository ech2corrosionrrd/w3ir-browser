## Ключове рішення

**ШІ підключається через Claude Code по MCP** (підписка власника, без API-ключа). Anthropic не дозволяє сторонніх програм із входом через акаунт підписки, тож вбудований чат із власним ключем **відкладено**: потрібен буде лише якщо з'явиться офіційний шлях або знадобиться локальна модель (Ollama). Увесь розвиток ШІ-напряму зосереджено на тому, щоб Claude Code працював у браузері максимально корисно **й безпечно**.

Принципи (діють для кожного етапу):

1. **Безпека й приватність понад усе**: нове з мережею чи секретами — вимкнено за замовчуванням; секрети лише в DPAPI/зашифрованому сховищі; ШІ нічого не бачить без явної дії користувача.
2. **Кожна функція — з тестами** (`test/security.js`), довідкою, підказками, записом у `CHANGELOG.md`, оглядом у `SECURITY.md`.
3. **Без нових збирачів і фреймворків**: HTML/CSS/JS, суворий CSP. Tailwind не потрібен.
4. **Публікація — лише за явною командою власника** (`npm run release:github`).

## Етап 2. Claude Code бачить те, що ви показали — ✅ 1.13.0

**Ціль:** «проаналізуй цю сторінку» без перенесення тексту вручну, але **лише за вашою явною дією**.

- Команда «Поділитися цією вкладкою з ШІ» (меню вкладки, Ctrl+K): вкладка стає доступною агенту **лише для читання** (текст, знімок елементів, скріншот), доки не натиснете «Припинити» або не закриєте вкладку. Кліки й ввід у ваших вкладках **не дозволені**.
- Виключено завжди: інкогніто, внутрішні сторінки `w3ir://`, поля паролів (їх значення не передаються), сторінки зі списків загроз.
- Помітний **індикатор у вікні**: на спільній вкладці — значок «Бачить ШІ»; у головному вікні — «ШІ активний». Усі читання потрапляють у журнал (без вмісту).
- Додаткові інструменти для роботи в ізольованому вікні: `browser_wait_for` (дочекатися тексту), `browser_find` (знайти за текстом), вибір пункту `<select>`, наведення курсору, скріншот елемента; підтримка однорівневих iframe (читання).
- Безпека: передача вмісту підпорядковується тим самим обмеженням (позначка «недовірені дані», ліміт розміру), окремий IPC й токен не змінюються; тести на ін'єкцію інструкцій із сторінки, на неможливість діяти у спільній вкладці, на відкликання доступу.

## Відкладено

- **Вбудований чат ШІ з власним ключем / Ollama, лічильник токенів:** не потрібні, поки Claude Code через MCP вистачає. Повернутися, якщо захочете локальну модель без хмари (Ollama) або Anthropic офіційно дозволить вхід підпискою для сторонніх.
- **Режим «ШІ у вашому профілі з вашими входами»:** свідомо не робимо.
- **Solana/TON-баланси й гаманці:** гаманець зараз EVM; нові мережі = нові ключі, RPC, розшифровка транзакцій і незалежний аудит.
- **Rarity Engine (NFT-слайдери):** схоже на окремий продукт власника, не на функцію браузера.
- **Tailwind/збирач:** не потрібні.
