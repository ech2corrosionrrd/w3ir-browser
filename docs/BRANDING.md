# Фірмовий стиль

Концепція (жовтень 2026) лежить у `build/brand/`: `concept.pdf` (текст), `concept-logo.jpg` (логотип), `concept-ui-kit.jpg` (набір інтерфейсу). Усі ресурси застосунку **генеруються з них** командою `npm run icon` (`build/make-brand.py`; потрібні Python 3, Pillow, numpy, scipy), тож замінити зображення-джерело й перезібрати — одна команда.

## Ідея назви й знака

- **W3** — World Wide Web / Web3; **IR** — Information Retrieval (пошук і впорядкування даних, у т. ч. за допомогою ШІ).
- Українська гра слів «Взір»: «W» читається як повернена літера, «3» — як «з», «IR» завершує слово. Поєднує технічну назву з образом уваги, ясності й зразка.
- Знак — око в скляній сфері: верхня дуга виростає зі «скриптової» W, нижня обрамляє «IR», зіниця — кіберпанківська цифра **3** (центр Web3).
- Назву слід завжди подавати з підписом **Browser** (вимога для вітрин і маніфестів).

| Роль | Значення |

| Акцент у темній темі й інтерфейсі | `#8B7CF6` |
| Додатковий неоновий (активний стан, індикатори) | кібер-бірюза `#00F2FE` |
| Акцент у світлій темі | `#5B3FD0` |
| Градієнт кнопок `primary` | `#2563EB` → `#7C3AED` |
| Неонові відблиски нової вкладки | рожевий `#F472B6`, блакитний `#38BDF8`, пурпурний `#8B5CF6` |

**Інтерфейс (1.14.0).** Темна тема — глибокий індиго: панель вкладок `#0B0A1F`, адресний рядок і панелі `#1C1947`, поле адреси `#14122F`; світла — лавандові відтінки. Панель інструментів і закладки мають тонку «сітку даних» (концепт «Top Bar»), активна вкладка — градієнтну лінію бірюза → фіолет угорі, поле адреси при фокусі — м'яке неонове світіння, меню й палітра — індиго з градієнтним відблиском. Режим **інкогніто** лишається окремим (чорно-фіолетовий з маджентою), щоб його не плутали зі звичайним вікном. Сторінки (`pages.css`): м'які рожево-блакитні відблиски тла, градієнтні заголовки, акцентна смужка розділів, «скляні» блоки; налаштування мають бічну навігацію розділами (від ширини вікна 1320 px).

## Ресурси

| Файл | Призначення |
|---|---|
| `build/icon.png` (256) | значок застосунку, вікон, ярлика й інсталятора |
| `build/brand/icon-512.png` | велика версія значка (для вітрин, README) |
| `pages/brand-mark.png` | знак із м'яким краєм для темних фонів (нова вкладка) |
| `pages/brand-wordmark.png` | вордмарк «W3IR BROWSER» на прозорому тлі (срібло + синя «3»); для **темних** фонів |
| `pages/brand-favicon.png` | значок вкладок внутрішніх сторінок |
| `build/installerSidebar.bmp`, `installerHeader.bmp` | зображення майстра NSIS (24-бітні BMP) |

Нова вкладка (`pages/newtab.*`) завжди фірмова темна (індиго, неонові хвилі, «скляні» картки) незалежно від теми системи. Вордмарк на світлому тлі не використовувати: срібні літери зливаються.

## Примітки

- Протокол `w3ir://` віддає лише файли з **плоскої** теки `pages/` (за іменем файлу): підтеки для ресурсів не працюють.
- Назви CSS-класів `word` та `wordmark` різні навмисно: `.word` — слово сид-фрази гаманця.
